# Changelog for external tool developers
This document contains changelog for technical changes to Customize+ which might be useful to you if you are working on any tools which are integrating with Customize+ or its data.

**If you are regular user this is not relevant to you, refer to changelog in the plugin.**

### 2.2.1.0

* Profile file version has been bumped to 6
	* "Source" field has been added. This field is mapped to DataSource enum.
* Template file version has been bumped to 7
	* "Source" field has been added. This field is mapped to DataSource enum.
